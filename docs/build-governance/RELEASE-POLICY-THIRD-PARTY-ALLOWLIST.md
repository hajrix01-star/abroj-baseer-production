# RP-TPA1 — قائمة سماح وحدات التقارير الخارجية في النشر

## عقد البناء — G0 (معتمد)

- **الهدف:** نشر إصلاحات تقارير `eh_account_base` و`eh_account_dynamic_reports` من مرشح Git المراجع، من دون فتح النشر لكل مجلد `third_party_addons`.
- **المستخدم:** مهندس التشغيل الذي ينفذ أمر النشر المحمي فقط.
- **النطاق:** حقل سياسة اختياري `THIRD_PARTY_MODULES`، والتحقق من أسماء الوحدات ومساراتها، وترقيتها مع الوحدات المعتمدة في نفس الإصدار.
- **خارج النطاق:** أي تغيير في قاعدة البيانات التجارية، أو السماح العام بالإضافات الخارجية، أو `compose.production.yaml` أو `config/`، أو وحدات `odoomates`.
- **معايير القبول:**
  1. لا تقبل السياسة إلا وحدات `eh_*` فريدة وموجودة كإضافة أودو.
  2. يرفض النشر أي ملف خارجي تغيّر خارج الوحدة المذكورة صراحة في السياسة.
  3. يرقّي Odoo الوحدات المصرح بها فقط، مع الاحتفاظ بالنسخ الاحتياطي والتراجع الحاليين.
  4. سياسة هذا الإصدار تسمي بالضبط `eh_account_base,eh_account_dynamic_reports`.
- **قرار المسار المباشر:** توسيع حارس النشر بقائمة سماح صريحة أفضل من نسخ تعديل التقرير إلى طبقة توافق جديدة؛ لأنه يحافظ على مالك السلوك الفعلي ويمنع ازدواج أصول الواجهة.
- **التراجع:** تبقى آلية النشر الحالية تستعيد قاعدة البيانات والـ filestore والمصدر السابق تلقائياً عند أي فشل؛ وكود الحارس نفسه يرجع عبر commit مستقل.

## G1 — السعة والاستمرارية (معتمد)

لا توجد رحلة مستخدم جديدة أو حمل جديد. المسار الإضافي يتحقق من قائمة قصيرة من أسماء الوحدات مرة واحدة لكل نشر. تظل حدود المساحة والنسخة الاحتياطية وانتظار الدخول كما هي في الحارس الحالي.

## G2 — عقد التشغيل والحماية (معتمد)

مصدر الحقيقة هو ملف سياسة الإصدار المسجل جذرياً على الخادم بعد جلبه من commit محدد في Git. تقبل السياسة حقلاً واحداً إضافياً فقط: قائمة مفصولة بفواصل، كل اسم فيها يطابق `eh_[a-z0-9_]+`. يطابق الحارس كل مسار متغير تحت `third_party_addons/erp_heritage_19/<module>/...` بالقائمة نفسها، ويرفض أي جذر أو إضافة أو ملف تشغيل خارجها. تخضع الوحدات الخارجية لنفس تحقق وجود الـ manifest وحالة وحدة Odoo وترقية `-u` التي تخضع لها وحدات Baseer.

## G3 — التقنية والتحقق (معتمد)

لا مكتبات أو رصة جديدة. التحقق: `bash -n` للغلافين، مراجعة فرق المسارات، وتجربة نشر QA من commit المجمد قبل الحية. حارس البوابات: مراجعة تسليم ألفا مستقلة قبل استدعاء الإنتاج.
