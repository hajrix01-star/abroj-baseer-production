معايير القبول:
1. الأسماء والقوائم والهوية الظاهرة موحدة، AR/EN مع IDs القديمة ثابتة.
2. مدير مخول يفتح إدارة موحدة ضمن شركاته؛ مستخدم عادي أو شركة غير مخولة

   وتوضح الاكتمال/الحدود. سياسة افتراضية تحفظ جميع الملفات المرتبطة، وحد
   تحذيري اختياري0=غيرمحدد؛ لا حذف مرتبط أو فرض حد رفع جديد بصمت.

   الدورية، دون اختلاق قياسات تأخير غير مسجلة أو طباعة محتوى/أسرار.
5. إشعارات العميل: التسجيل للحساب الحالي، إلغاء آمن عند الخروج/تبدل الحساب،

   لا طلب إذن حتى يرغب المستخدم. إعادة استعمال Firebase المثبت فقط إذا كان
   إعداد عام مطابق للحزمة موجودًا ومخولًا؛ لا اختلاق مشروع/سر/تفعيل مدفوع.
6. اختبارات أودو معزولة والعميل/العقود الحالية تبقى ناجحة؛ معاينة AR/EN
   ضيقة/سطح مكتب؛ PR ناجح ومراجعة مستقلة قبل QA/APK. نجاح workflow=QUEUED
   لا إثبات اكتمال الخادم، والفحص المالي السابق يبقىUNTESTED حتى دليل فعلي.
