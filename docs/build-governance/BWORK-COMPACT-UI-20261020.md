## تحقق المصدر

ست حالات حماية جديدة: نافذة اليوم، شبكة الشهر/السنة والإلغاء، سحب السياق،
حدود السنوات دون تحويل توقيت، وهيدر الطلبات والمهام. اختبارات RED ثم GREEN
محلية؛ البوابة توقفت أولًا قبل الاختبارات على تعريف absoluteFillObject
غير الموجود في shim المشروع؛ صُحح التنسيق محليًا دون تعديل shim أو العقود.
البوابة المتكاملة بعد الإصلاح:562PASS/0FAIL،159ثابتًا وTypeScriptPASS،18.09s؛
benchmark اختياري قديم واحد غير مشغّل. لا اختبارات محذوفة أو skip جديد.
المعاينة الضيقة والمراجعة المحددة تتبعان المصدر المجمد؛ لا نشر.

المراجعة المستقلة المحددة وجدت أن callback قديمًا لمنتقي الشهر يستطيع
اعتماد اختيار بعد الإلغاء/التعطيل. لذلك أوقف بناء المعاينة قبل بدايته؛
إغلاق دورة الفتح بحارس حي واختبار callback مؤجل مطلوب قبل إعادة التجميد.
هذه ملاحظة للمكوّن الجديد في فرع العمل، لا انحدار في APK المنشور السابق.

أُغلقت الملاحظة بحارس عمر المكوّن ورقم دورة فتح حي، مع تحصين callbacks
بعد الإلغاء/التعطيل/تغير القيمة أو callback/إعادة الفتح/التفكيك. الحالة
السابعة للحماية RED ثم GREEN، والباقي دون تغيير. البوابة بعد هذا الفرق
المحدد563PASS/0FAIL،160ثابتًا وTypeScriptPASS،17.56s؛ المعاينة لم تبدأ قبل
التصحيح. السجلات الأولية والنهائية في output/bwork-ui-compact-20261020.
