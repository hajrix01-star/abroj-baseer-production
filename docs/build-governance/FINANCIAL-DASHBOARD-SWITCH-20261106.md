# FINANCIAL-DASHBOARD-SWITCH-20261106

## عقد البناء

- **الهدف:** إضافة لوحة بيانات مالية مستقلة في تطبيق «لوحات البيانات» تحتوي مبدّلًا واضحًا بين **الأداء المالي — الربح والخسارة** و**ملخص المبيعات والمدفوعات**.
- **المستخدم:** مالك الشركة والمحاسب المصرح له بقراءة البيانات المالية للشركة النشطة.
- **النطاق:** لوحة واحدة، تبويبان، حالة تحميل/خطأ/فراغ ثنائية اللغة، وفلاتر كل تبويب المعتمدة في مصدره. النقر على التفاصيل يفتح المصدر بآليات الصلاحية الأصلية فقط.
- **خارج النطاق:** تغيير التقريرين النصيين في «تقارير بصير» أو حساباتهما أو تصديرهما، إنشاء أو تعديل قيود أو فواتير أو دفعات، أي تغيير لزاتكا، أو نشر LIVE.

### معايير القبول

1. يظهر مدخل «الأداء المالي» في لوحات البيانات، ولا يظهر على أنه تقرير جديد داخل «تقارير بصير».
2. يبدّل المستخدم بين التبويبين بلوحة مفاتيح أو فأرة/لمس، مع دلالة تبويب نشط وإتاحة سليمة، من دون إعادة حساب الأرقام في العميل. التبويب غير النشط لا يحمّل مسبقًا ولا يبقى قابلًا للتركيز.
3. تبويب الربح والخسارة يعرض فقط القيود المُرحّلة المرئية للمستخدم من محرك `baseer.profit.loss.report` القائم.
4. تبويب ملخص المبيعات والمدفوعات يعرض بالضبط عقد `baseer.operations.report.get_owner_snapshot` القائم وبحدوده الحالية؛ يوضح أن «الفرق» ليس ربحًا محاسبيًا ولا يدّعي تحصيلًا بنكيًا أو تسوية.
5. يبقى تقريرا «الربح والخسارة» و«ملخص المبيعات والمدفوعات» داخل «تقارير بصير» جدوليين/نصيين قابلين للتصدير كما قبل هذه اللوحة.
6. تعمل العربية والإنجليزية وRTL/LTR والجوال 390px وسطح المكتب، وتظهر الأرقام الغربية `0-9` فقط.

### خريطة الرقابة المالية

`account.move.line` المُرحّل → محرك الربح والخسارة القائم → تبويب P&L.

مصادر المبيعات/المدفوعات التي يتحقق منها `baseer.operations.report` → لقطة ملخص المبيعات والمدفوعات القائمة → التبويب الثاني.

لا يملك المبدّل المالي مصدر أرقام أو تجميعًا أو تقريبًا أو كتابةً؛ يختار المكوّن فقط ويعرض القيم المنسقة خادميًا. تفصيل أي قيمة يعيد فحص الصلاحية في المصدر المالك قبل الفتح. صلاحية كل تبويب مستقلة: ظهور اللوحة لا يمنح صلاحية التقرير الآخر ولا يضيف مجموعة أو سجل صلاحية. عند تغيير الشركة أو الفترة أو فقدان الصلاحية، يمسح المكوّن البيانات السابقة ويلغي/يتجاهل استجابة الطلب السابق قبل أي عرض.
