## G0: عقد البناء

الهدف إتاحة لوحة QA ذات تبويبي الأداء المالي وملخص المبيعات والمدفوعات في الأصلية، مع إبقاء ملفات وسلوك تقارير بصير في الفوترة دون تغيير. المستخدم المدير أو المحاسب المصرح؛ المسار فتح لوحة البيانات ثم اختيار تبويب وفترة وشركة ودفاتر مرخصة. لا ترحيل أو تعديل قيد أو فاتورة أو دفعة، ولا نقل بيانات أو إعداد نوركس.

دورة الرقابة: القيود المرحلة تبقى مصدر الحقيقة عبر تقرير الربح والخسارة الموجود؛ ملخص العمليات يبقى مصدر تبويب المبيعات والمدفوعات. الحساب وعزل الشركات والتحقق من الدفاتر والصلاحيات خادمي؛ الواجهة تعرض القيم فقط. قبول: تطابق اللوحة مع التقريرين وصورة QA مع AR/EN و390px، مع إثبات ثبات ملفات ومخرجات تقارير الفوترة قبل/بعد، واختبارات منع غير المصرح وتبديل الشركات والمردودات والبنود الأخرى، وعدم كتابة البيانات المالية.

## G2: المعمارية
