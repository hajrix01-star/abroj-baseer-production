# حوكمة بناء ونشر بصير أودو

## الحالة السارية — 2026-09-16

هذا المستند هو المرجع التشغيلي الوحيد للنشر والاسترجاع. أزيلت منه العقود
التجريبية السابقة، وسياسات SHA الأحادية، ومسارات الأرشيف أو الطرفية اليدوية.
تاريخها محفوظ في Git ولا يصلح لتشغيل الإنتاج.

| المجال | الوضع الساري |
| --- | --- |
| مصدر الكود | `main` في `hajrix01-star/abroj-baseer-production` |
| مسار النشر التشغيلي | يدوي من GitHub Actions؛ غلاف النشر لا يقبل إلا سياسة محفوظة مسبقًا |
| مدخل Action | `release_id` مسمى + كلمة تأكيد ثابتة فقط |
| قرار المكونات وcommit | سياسة إصدار محفوظة على الخادم بصلاحية `root:root,0600` |
| حساب النشر | `baseer_deploy` محدود بغلافي اعتماد/نشر ثابتين؛ لا root ولا Docker عام |
| مصدر الخادم | مفتاح GitHub للقراءة فقط محفوظ `root-only` |
| التزامن | قفل خادم مشترك بين الاعتماد والنشر |
| التراجع | الإصدار السابق + زوج PostgreSQL وfilestore متسق |

## العقد

```text
GitHub: اعتماد release_id
  -> الخادم يثبت سياسة الإصدار: commit كامل + موديولات مسموحة
GitHub: نشر release_id نفسه
  -> الخادم يتحقق من السياسة ويجلب المصدر بنفسه
  -> backup متسق -> ترقية محددة -> health أو rollback كامل
```

لا تعرض الـActions للمستخدم SHA أو قائمة موديولات أو مسار أرشيف؛ الإدخالان
الوحيدان هما `release_id` وكلمة التأكيد الثابتة. يمرر Workflow الاعتماد
`GITHUB_SHA` تلقائيًا كمرجع للسياسة، ثم يتحقق الخادم من السياسة والـcommit
والموديولات بنفسه. أي سياسة غير محمية، أو commit غير موجود على `main`، أو موديول
غير موجود في ذلك commit، أو نقص في السعة، يوقف العملية قبل توقف أودو.

## حدود حماية GitHub

بيئة GitHub المسماة `production` مستخدمة في الـActions، لكن لا توجد قاعدة
مراجعين إلزاميين أو تقييد فروع ظاهر في إعداد البيئة الحالي. الحماية المثبتة
حاليًا هي التشغيل اليدوي من `main`، كلمات التأكيد، مدخلات محدودة، حساب SSH
مقيد بأغلفة `sudo` ثابتة مع تعطيل TTY والتحويلات، وسياسة خادمية `root-only`.
إضافة مراجعين إلزاميين أو حماية فروع قرار حوكمة لاحق وليست حماية ندّعي وجودها
الآن.
