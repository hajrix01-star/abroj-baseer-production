# رابط التحميل المباشر في مركز الوكيل

يعرض نموذج الإصدار المعتمد رابط GitHub كعنوان مباشر قابل للضغط والنسخ على الجوال. يظل ملف الربط متاحًا من زره المستقل.

التزام «Prepare live-only print agent link snapshot» يحفظ نسخة جسر اللايف السابقة مع تعديل الواجهة فقط. يعيد الالتزام التالي شجرة التطوير كاملة. يلزم دمج الالتزامين بخيار rebase، ثم مطابقة بصمة شجرة الوحدة مع اللقطة المفحوصة قبل إجازة سياسة اللايف.
