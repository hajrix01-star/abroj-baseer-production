# BWork Legacy Preview

Current source: `android/bwork-legacy`, Java namespace `com.baseer.bwork.legacy`.
This is a distinct legacy preview, not the canonical React Native application in
`mobile/bwork`. Its installed application ID, signing alias, storage keys and old
shortcut component are bounded exceptions in
`mobile/bwork/compatibility/identities.json`; no queues or application containers
are merged. The original v1/v2 serialized snapshots remain read-only inputs to the
bounded compatibility reader. Historical evidence below is intentionally unchanged.

## حالة candidate01 السابقة · 0.5.0
هذه نسخة مصدر أُعيد بناؤها بعد فقدان بيئة التطوير، وتخضع لاختبارات جديدة. اجتاز المصدر البناء دون توقيع واختبارات أساسية مستقلة. بتاريخ 2026-10-08 وافق المالك على تطبيق معاينة مستقل بتوقيع جديد إلى جانب التطبيق القديم. أُنتج candidate01 باسم BChat Preview 0.5.0 وحزمة com.baseer.bchat.preview؛ اجتاز ملف APK نفسه اختبارات عادية محددة على API 29، واجتازت API 27 الاختبارات العادية والوسائط والفقاعات؛ كشف اختبار API 35 لاحقًا عيب إعداد اللغة والدوران، فاستُبعد candidate01 وصُحّح في candidate02 الموثق أعلاه.

مفتاح توقيع com.baseer.freshchat الأصلي غير متاح؛ لذلك يظل تحديث التطبيق القديم بالحزمة والتوقيع نفسيهما متعذرًا. المعاينة المستقلة لا تحدّث 0.4.4 ولا تستورد محادثاته أو مسوداته أو مرفقاته ولا تشارك مساحة بياناته. **احتفظ بالتطبيق القديم وبياناته ولا تحذفه.** تفاصيل هوية المرشح وحدود التثبيت في [INDEPENDENT_PREVIEW.md](../../docs/bchat/INDEPENDENT_PREVIEW.md).

تتضمن الأساسات تخزينًا تدريجيًا مع حفظ بايتات النسخة السابقة، وغير مقروء محفوظًا، وحفظًا مترابطًا للمسودة والمرفقات والرد، واستعادة صريحة من حفظ سابق، ونوافذ للسجل والبحث، وتكبير الصور، ومعاينة PDF في الخلفية، وفحص اكتمال الاستيراد وبصماته. يبقى الحذف التلقائي متوقفًا. الملفات القديمة والكاميرا والتسجيلات غير المبصومة لا تُوثق بأثر رجعي.

يحافظ نموذج المحرر الآن على البصمة المعروفة للمرفق نفسه عند تعديل النص. أُضيف سجل لحالات قبول الالتقاط، لكنه غير موصول بالكاميرا أو التسجيل بعد؛ لا يُعد قبولًا عمليًا لهذه المسارات. تفاصيل شروط الربط في CAPTURE_ADMISSION_CANDIDATE.md.

النتائج الدقيقة والقيود في VALIDATION_0_5_0.md و../../docs/bchat/STORAGE_V4.md. نتائج اختبارات Android الأساسية السابقة تخص تشغيل DEX دون تثبيت حزمة؛ لا تُعد بحد ذاتها قبولًا لواجهة التطبيق أو APK المرشح الجديد. أُضيفت لاحقًا أدلة مستقلة للملف الموقع نفسه على API 29، مع بقاء حدود الأجهزة الفعلية والمسارات غير المختبرة. إضافات الخادم وDMS والمصادقة والإشعارات البعيدة غير مفعلة، والطلبات والمهام في Android أمثلة محلية.

البناء من المصدر يحتاج SDK رسميًا. البناء الموقع للحزمة المستقلة يستخدم مفتاح المعاينة المصرّح به من خارج Git عبر BCHAT_SIGNING_KEY وBCHAT_SIGNING_PASSWORD_FILE؛ لا تولّد أدوات البناء مفتاحًا بديلًا تلقائيًا. المفتاح وكلمة مروره محفوظان محليًا فقط، ولم يُنشأ لهما بعد نسخ احتياطي آمن ودائم؛ فقدانهما يمنع تحديثات متوافقة مع هذه المعاينة. لا يُرفقان بالمصدر أو ملفات التسليم. متغير BCHAT_UNSIGNED_ONLY=1 يسمح بفحص البناء فقط؛ الناتج غير موقع وليس ملف تثبيت. لا ترجع إلى نسخة أقدم بعد ترحيل بيانات حقيقية إلى v4؛ النسخ القديمة لا تقرأ الصيغة الجديدة. وجود منطق ترحيل التخزين داخل التطبيق لا يتيح نقل بيانات التطبيق القديم إلى الحزمة المستقلة.

### تشغيل توقيع BChat على Windows

المخزن المحلي المعتمد للإصدار الحالي هو `%LOCALAPPDATA%\Baseer\BChatSigning\fresh-install-20261009\`، ويحتوي ملف المفتاح `bchat-preview-fresh.p12` وملف كلمة المرور `keystore.password`. قبل أي بناء موقّع، على المنفذ فحص وجود الملفين ثم تحميل مساريهما في **جلسة البناء فقط** كـ `BCHAT_SIGNING_KEY` و`BCHAT_SIGNING_PASSWORD_FILE` وتشغيل `tools/build-unified-preview.ps1`. لا يطلب المنفذ من المالك قيمة كلمة المرور، ولا يطبعها، ولا ينسخ أيًّا من الملفين إلى Git أو مجلد `artifacts`. إذا غاب أحد الملفين يفشل البناء بأمان؛ لا يُنشأ توقيع بديل ولا APK غير موقّع للتوزيع.

- التثبيت الجديد والتحديث يعرضان صفحة الدخول. «تذكرني» يحفظ الدخول التجريبي بعد إنهاء عملية التطبيق؛ بدونه تبقى الجلسة خلال العملية الحالية فقط. لا تُحفظ كلمات مرور. الخروج يحفظ المحادثات والملفات والمسودات ويوقف الصوت ويلغي التسجيل غير المكتمل والتنبيه التجريبي المنتظر. حالة الدخول المحلية ليست حماية للبيانات أو صلاحيات حقيقية.
- لا يزال الحذف التلقائي للمرفقات متوقفًا. اجتاز **نفس ملف APK** اختبارات الاستخدام الأساسية على محاكي Android 10/API 29؛ لم يُعد اختبار API 27 لهذا الملف النهائي. راجع VALIDATION.md للنتائج والحدود.

## معاينة الهوية والأقسام
- الاسم الإنجليزي BChat، وعلامة B الأصلية من المستودع بلا تعديل لبايتات PNG، مع Chat باللون السماوي وهوية كحلية.
- الأقسام الرئيسية: المحادثات، طلبات الشراء، المهام. بطاقات الطلبات والمهام أمثلة خيالية معلّمة PREVIEW؛ أزرار إنشاء سجلات العمل معطّلة. لا أرقام أداء أو طلبات أو مهام حقيقية.
- الوردية Shift والمؤشرات والإعدادات في القائمة العلوية. الوردية والمؤشرات غير متاحتين قبل تكامل الخادم.
- قائمة المحادثة تضم البحث والنسخ وتفاصيل الأعضاء والكتم والمهام/الطلبات المرتبطة؛ الربط بسجلات حقيقية غير مفعّل.
- مجموعات العمل تحتاج مديرًا مخوّلًا وسياسة خادم لم تُربط بعد. إنشاء المجموعة المحلية التجريبية منفصل وواضح بأنه لا يمنح صلاحيات حقيقية.

## قائمة موحّدة ومجموعات محلية
- تعرض الشاشة الرئيسية كل المحادثات في أقسام تحمل اسم الشركة؛ المجموعات أولًا داخل كل قسم. لا يوجد مبدّل شركة أعلى القائمة.
- شريط العلامة بارتفاع 56dp في الأعلى. الأقسام الثلاثة في شريط ثابت أسفل الشاشات الرئيسية فوق مساحة النظام، خارج محتوى التمرير، ولا تظهر داخل المحادثة أو المنتقي أو الإعدادات. البحث مخفي حتى تضغط أيقونته، والتصفية تحت قائمة ⋮.
- البحث والتصفية يعملان عبر الشركات الخيالية المعروضة. داخل المحادثة يظهر اسمها واسم شركتها.
- اضغط + ثم «مجموعة تجريبية»، ثم أدخل اسمًا واختر الشركة صراحة وحدد أعضاء من أشخاصها التجريبيين. لا توجد دعوات أو عضوية أو صلاحيات خادم فعلية.
- يبقى لكل محادثة وشركة نص مسودة ومرفقات ورد مقتبس مستقل.

## المشاركة والمرفقات والصوت
1. من الصور/الملفات/الصوت في Android اختر مشاركة إلى BChat. تظهر كل الوجهات المتاحة مع اسم الشركة؛ اختر المستلم ثم راجع المعاينة واضغط إرسال لحفظ رسالة محلية.
2. لا تُرسل المشاركة تلقائيًا إلى آخر محادثة. العودة والإلغاء لا يغيّران مسودة محادثة أخرى؛ يمكن الاحتفاظ بالمشاركة لاختيار مستلم لاحقًا.
3. مشبك المرفقات يتيح صورة أو PDF أو صوتًا أو ملفًا آخر أو الكاميرا أو التسجيل الصوتي.
4. تُنسخ **البايتات الأصلية التي يقدّمها التطبيق المصدر دون إعادة ضغط**. الصورة المصغّرة مخصصة للعرض فقط. ملفات الصوت وPDF والملفات العامة تُحفظ كما استُلمت.
5. اضغط المرفق لمعاينته؛ PDF يعرض الصفحة الأولى وعدد الصفحات إن أمكن، والصوت له زر تشغيل صريح. الملفات العامة تعرض معلوماتها فقط؛ لا تُنفّذ ولا تُفتح خارجيًا تلقائيًا. الملف غير القابل للمعاينة يظل قابلًا للحفظ كأصل.
6. «حفظ نسخة…» يفتح منتقي Android لتختار مكان الحفظ. لا يطلب إذن تخزين شامل.
7. عندما تكون خانة الكتابة فارغة، اضغط مطولًا على زر الميكروفون. بعد منح الإذن يبدأ طلب التسجيل مباشرة دون نافذة تسجيل منبثقة. أول طلب إذن لا يبدأ التسجيل تلقائيًا بعد الموافقة؛ اضغط مجددًا.
8. اسحب جانبًا للإلغاء أو للأعلى لقفل التسجيل دون إمساك الزر. عند القفل استخدم زر الإيقاف للمعاينة أو الإلغاء. الإفلات من الضغط المطوّل يوقف التسجيل ويضعه في المسودة **ولا يرسله**. شريط التسجيل كامل العرض يعرض عداد الزمن الفعلي ومستوى الميكروفون المقاس. لا نرسم موجة زخرفية مصطنعة.
9. تظهر معاينة صوتية كاملة العرض قبل الإرسال، وشكل مصغّر عند ضيق النافذة/فتح لوحة المفاتيح. نفس المشغّل موجود داخل الرسالة ومعاينة الملف: مدة حقيقية، تشغيل/إيقاف مؤقت، تقديم وترجيع بعد تجهيز الصوت، وسرعات 1× و1.5× و2× إن دعمها الجهاز. زر الإرسال مستقل عن الإفلات؛ يمكن حذف المقطع من المسودة.
10. للتسجيل بالنقر أو مع أدوات إمكانية الوصول: المرفقات ← «تسجيل صوتي بالنقر»، ثم الإيقاف/الإلغاء من الشريط. هذه الطريقة تبدأ في وضع القفل.
11. الحد دقيقتان أو 2 MiB؛ التسجيل AAC/M4A أحادي 64 kbps. التسجيل الأقصر من نحو 0.75 ثانية قد يُرفض. **مغادرة التطبيق أو الرجوع أو دوران الشاشة يلغي التسجيل حتى عند القفل** ويحرر الميكروفون. المسودات المحفوظة سابقًا تبقى كما هي.

يُفك الصوت إلى عينات PCM محليًا لرسم الموجة دون تغيير الملف الأصلي. يقتصر التحليل على ملفات حتى 10 دقائق، بمهلة 20 ثانية و8 طلبات تحليل كحد أقصى. تُلغى الطلبات عند إزالة مشغّلها من الشاشة؛ النتائج مخزّنة في الذاكرة فقط وبحد 32 ملفًا. الصوت غير المدعوم أو الطويل يظل قابلًا لمحاولة التشغيل والحفظ مع عبارة «الموجة غير متاحة». الصمت الحقيقي يظهر مسطّحًا. التحليل ليس اختبارًا لعمل MediaCodec على كل جهاز.

مشغّل واحد فقط يمكنه امتلاك الصوت. تشغيل مقطع آخر يوقف السابق ويعيد أزراره؛ الإرسال والحذف والتنقل وخروج التطبيق يوقفونه. فقدان تركيز الصوت يوقفه مؤقتًا دون استئناف تلقائي. تبديل السرعة غير المدعوم يحافظ على آخر سرعة نجحت.

الحدود: 10 مرفقات في الرسالة، 25 MiB للملف، 100 MiB للدفعة/المسودة، و20,000 حرف للنص. قد يرفض Android تشغيل أو معاينة بعض الصيغ؛ الملف العام لا يُعامل كبرنامج.

## الرد والبحث والنسخ
- اضغط «رد» بجانب وقت الرسالة أو اضغط مطولًا عليها/على مرفقها لاختيار الرد أو النسخ. يظهر اقتباس مرتبط بالأصل؛ الضغط عليه يعرض الرسالة الأصلية ومرفقاتها.
- الرد المختار محفوظ مع المسودة. إلغاء الرد يحتفظ بالنص والمرفقات، والإرسال المحلي يستهلك هذه المسودة فقط.
- أيقونة البحث داخل المحادثة تبحث في **كل السجل المحلي المحفوظ** ونصوصه وأسماء مرفقاته، وليس الصفحة المرئية فقط. الأسهم تنتقل بين النتائج ويُميّز إطار النتيجة الحالية؛ إغلاق البحث يعيد أحدث الرسائل.
- من خيارات المحادثة اختر «نسخ نص المحادثة كاملًا». النص يتضمن الشركة والمحادثة والأسماء وأوقات UTC؛ المرفقات بأسمائها فقط، دون بايتاتها أو مساراتها الخاصة. النسخ لا يتضمن مسودات أو محادثات أخرى. إذا رفضت الحافظة الحجم، يمكن حفظ النص كاملًا كملف.
- الوقت المعروض في فقاعات الدردشة هو وقت الجهاز. لا توجد علامات استلام أو قراءة حقيقية؛ الرسائل الجديدة موسومة بأنها على هذا الجهاز فقط.

## الحذف المحلي والتراجع
- اضغط مطولًا على رسالة أنشأتها محليًا، ثم «حذف محلي»، ثم وافق على مربع التأكيد. إلغاء المربع لا يغيّر الرسالة.
- يظهر عنصر «رسالة محذوفة محليًا» بدل المحتوى. لا يتسرب النص أو أسماء المرفقات المحذوفة إلى البحث أو النسخ أو الردود المقتبسة.
- اضغط مطولًا على العنصر المحذوف واختر «تراجع عن الحذف المحلي». التراجع محفوظ بعد إغلاق التطبيق؛ تحتفظ مساحة التطبيق الخاصة بالمحتوى اللازم له.
- الأمثلة الأولية ورسائل الآخرين لا يتاح حذفها هنا. هذا ليس حذفًا للجميع أو من خادم، ولا يحذف النسخ التي صدّرتها سابقًا إلى ملفات الجهاز.

## الإعدادات المحلية
- الصوت والاهتزاز محفوظان بشكل مستقل للمحادثات وطلبات الشراء والمهام. فئة المحادثات تُطبق على تجربة التنبيه اليدوية؛ الفئتان الأخريان تفضيلات محفوظة فقط ولا تنتجان تنبيهات قبل الربط.
- كتم المحادثة مستقل لكل شركة ومحادثة، ويمنع تجربة التنبيه لها، بما في ذلك المؤجلة.
- إخفاء التنبيه كاملًا من شاشة القفل هو الافتراضي؛ الخيار الآخر تنبيه عام دون أسماء أشخاص أو شركات أو محتوى محادثة. إعدادات قناة Android وعدم الإزعاج لها الأولوية.
- التنزيل التلقائي غير موجود لعدم وجود شبكة. التخزين يعرض حجم الملفات الخاصة وعددها وحدود الاستيراد. لا زر مسح جماعي أو تغيير خفي للاحتفاظ.
- الحساب يعرض حقيقة حساب العرض المحلي. من الإعدادات ← لغة الواجهة اختر العربية أو English؛ يُحفظ الاختيار ويُطبَّق اتجاه RTL/LTR على الواجهة والنوافذ والإعدادات ورسائل الخطأ وإمكانية الوصول والتنبيهات المحلية. تبقى الأسماء والرسائل المخزنة كما كُتبت، مع حفظ المسودات والمرفقات عند إعادة إنشاء الشاشة.
- المظهر فاتح محايد؛ الوضع الداكن ودخول الموظف غير متاحين بعد. دخول التجربة والخروج منها متاحان محليًا دون كلمات مرور.

## تجربة التنبيه والصوت
1. من قائمة ⋮ اختر «تجربة التنبيه والصوت»، ثم راجع الوجهة واختر «تنبيه الآن» أو «تنبيه بعد نحو 10 ثوانٍ».
2. في Android 13 وما بعده، يطلب التطبيق إذن الإشعارات عند بدء تجربة صريحة فقط. الرفض أو إغلاق الطلب لا يبدأ الاختبار.
3. للتأخير اضغط الشاشة الرئيسية. التنفيذ تقريبي ما دام التطبيق حيًا؛ إيقافه أو قتل عمليته أو توفير الطاقة قد يؤخر الاختبار أو يمنعه. لا توجد خدمة دائمة أو منبّهات دقيقة.
4. يتبع اختيارات صوت واهتزاز فئة المحادثات، مع احترام كتم المحادثة وعدم الإزعاج وإعدادات قناة Android. يمكن فتح إعدادات الصوت من نافذة التجربة. لا توجد نسخة من نغمة WhatsApp.
5. الضغط على التنبيه يفتح الشركة والمحادثة المحددتين. «إلغاء التجربة وإزالة التنبيه» يلغي الاختبار المنتظر والتنبيه الظاهر. اختبار جديد يستبدل المنتظر السابق.

هذه تجربة **محلية يدوية**، وليست إشعار رسالة واردة من خادم أو مستخدم. لم يُختبر مكبر الصوت والاهتزاز والميكروفون على هاتف فعلي. نتائج اختبارات Android الافتراضية موضّحة في VALIDATION.md.

## التحقق والبناء

```sh
export ANDROID_HOME=/path/to/android-sdk

```

## سياسة الإصدارات
كل تحديث يصل للمراجعة يحمل versionCode أعلى وversionName واضحًا واسم APK يتضمن الإصدار. لا نستبدل ملف إصدار موزّع ببايتات أخرى تحت الرقم نفسه. تتطلب التحديثات المتوافقة داخل كل حزمة ثبات معرّفها وتوقيعها: النسخ القديمة com.baseer.freshchat، والمعاينة المستقلة الجديدة com.baseer.bchat.preview. تغيير الحزمة لا يعني ترقية بيانات التطبيق القديم. تعرض الإعدادات ← عن BChat رقم النسخة المثبّتة من PackageInfo، ويتوفر «ما الجديد» داخل التطبيق. يفحص tools/check-package.py تطابق Manifest وGradle وسكربت البناء. يجوز تعديل بناء لم يُوزّع بعد تحت الرقم المعلّق نفسه، مع حفظ هوية كل مرشح وإعادة التحقق من ملفه نفسه قبل مشاركته.
