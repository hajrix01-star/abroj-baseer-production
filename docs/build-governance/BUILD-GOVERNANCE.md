# حوكمة بناء ونشر بصير أودو

## الحالة السارية — 2026-09-16

هذا المستند هو المرجع التشغيلي الوحيد للنشر والاسترجاع. أزيلت منه العقود
التجريبية السابقة، وسياسات SHA الأحادية، ومسارات الأرشيف أو الطرفية اليدوية.
تاريخها محفوظ في Git ولا يصلح لتشغيل الإنتاج.

| المجال | الوضع الساري |
| --- | --- |
| مصدر الكود | `main` في `hajrix01-star/abroj-baseer-production` |
| مسار النشر التشغيلي | يدوي من GitHub Actions؛ غلاف النشر لا يقبل إلا سياسة محفوظة مسبقًا |
| مدخل Action | `release_id` مسمى + كلمة تأكيد ثابتة فقط |
| قرار المكونات وcommit | سياسة إصدار محفوظة على الخادم بصلاحية `root:root,0600` |
| حساب النشر | `baseer_deploy` محدود بغلافي اعتماد/نشر ثابتين؛ لا root ولا Docker عام |
| مصدر الخادم | مفتاح GitHub للقراءة فقط محفوظ `root-only` |
| التزامن | قفل خادم مشترك بين الاعتماد والنشر |
| التراجع | الإصدار السابق + زوج PostgreSQL وfilestore متسق |

## العقد

```text
GitHub: اعتماد release_id
  -> الخادم يثبت سياسة الإصدار: commit كامل + موديولات مسموحة
GitHub: نشر release_id نفسه
  -> الخادم يتحقق من السياسة ويجلب المصدر بنفسه
  -> backup متسق -> ترقية محددة -> health أو rollback كامل
```

لا تعرض الـActions للمستخدم SHA أو قائمة موديولات أو مسار أرشيف؛ الإدخالان
الوحيدان هما `release_id` وكلمة التأكيد الثابتة. يمرر Workflow الاعتماد
`GITHUB_SHA` تلقائيًا كمرجع للسياسة، ثم يتحقق الخادم من السياسة والـcommit
والموديولات بنفسه. أي سياسة غير محمية، أو commit غير موجود على `main`، أو موديول
غير موجود في ذلك commit، أو نقص في السعة، يوقف العملية قبل توقف أودو.

## حدود حماية GitHub

بيئة GitHub المسماة `production` مستخدمة في الـActions، لكن لا توجد قاعدة
مراجعين إلزاميين أو تقييد فروع ظاهر في إعداد البيئة الحالي. الحماية المثبتة
حاليًا هي التشغيل اليدوي من `main`، كلمات التأكيد، مدخلات محدودة، حساب SSH
مقيد بأغلفة `sudo` ثابتة مع تعطيل TTY والتحويلات، وسياسة خادمية `root-only`.
إضافة مراجعين إلزاميين أو حماية فروع قرار حوكمة لاحق وليست حماية ندّعي وجودها
الآن.

  تنشئ قيدًا مباشرًا.

  وإعداد اليومية العام الموجودان للشركة. لا ينشئ حسابًا أو يومية تلقائيًا،
  ويوقف الترحيل برسالة واضحة إن لم يضبطهما المدير.

  إثباته الإلزامية للتمويل**، الحالة، وقيد اليومية الناتج. يظهر مبلغ الطلب من الخلفية:
  التقديري قبل الاستلام والفعلي بعده.
- يسمح بأكثر من عهدة للطلب نفسه. ينشأ `client_token` مرةً قبل أول `create`
  ويحفظه العميل في إعادة محاولة الحفظ نفسها؛ يفرض قيد SQL الفريد
  `(company_id, creator_id, client_token)` سجلًا واحدًا. إذا دوّن المحاسب
  مرجعًا خارجيًا، يفرض قيد فريد مشروط `(company_id, source_journal_id,
  external_reference)` عند عدم فراغه؛ المرجع الفارغ لا يمنع تحويلين مشروعين.
- يتحقق الخادم من أن المندوب شخص نشط مفعّل «مندوب مشتريات» ومطابق لمندوب
  الطلب والشركة؛ يقبل التمويل للطلبات `sent` أو `received` أو `purchased` فقط
  ويرفض المسودة والملغى.
- مصدر الحقيقة هو قيد Odoo المرحل: التمويل مدين حساب **عهد مندوبي المشتريات**
  ودائن بنك/كاش المؤسسة؛ والاسترداد بالعكس. يضاف رابط غير قابل للتعديل من
  `account.move.line` إلى العهدة الجديدة، ولا يعاد استعمال رابط العهدة القديم.
- يضاف إعداد شركة مستقل لحساب العهد القابل للمطابقة ويومية عامة. لا ينشئ
  النظام حسابًا أو يومية تلقائيًا ولا يعيد استخدام إعداد Petty Cash التاريخي.
- عند الترحيل يقفل الخادم سجل الحركة والطلب والعهدة عند وجودها، ويتحقق من
  الشركة والفترة والمندوب والمتبقي، ثم ينشئ ويرحّل القيد في معاملة واحدة.
  إعادة ترحيل السجل نفسه آمنة ولا تنشئ قيدًا ثانيًا.
- العملة هي عملة الشركة، والمبلغ موجب وبدقة عملة الشركة حتى منزلتين عشريتين؛
  يتحقق الخادم من ذلك قبل أي قيد ولا يجعل المتصفح مصدرًا للحساب. التمويل أو
  الاسترداد ينتقل مرة واحدة من `draft` إلى `posted` ويصبح بعدها غير قابل
  للتعديل أو الحذف.
- الكاشير بلا قراءة أو إنشاء أو ترحيل للعهد. المحاسب ينشئ ويرحل التمويل
  والاسترداد في عملية حفظ واحدة؛ لا تعرض له مسودة قابلة للتعديل بعد الحفظ ولا
  يملك حذف سجل مرحل. المالك يدير إعداد الشركة ويصحح الأثر المرحل بحركة
  عكس/استرداد مرتبطة بالأصل، لا بحذف أو تعديل صامت.

  أو صورة؛ مطابقة محتوى الملف الفعلية تحسين أمني لاحق وليست بديلًا عن مراجعة
  المدقق للمستند.
- كروت الشهر للمندوب والفترة المختارين: المحوّل، المسدد للمشتريات، والمتبقي.
  الفلتر عرض فقط؛ في المرحلة الأولى يظل المسدد صفرًا حتى تضاف تسوية الإدخال
  الجماعي في المرحلة الثانية، ولا يمس الرصيد أو التاريخ.
- العربية وRTL والجوال وسطح المكتب إلزامية، والأرقام والتواريخ الرقمية تعرض
