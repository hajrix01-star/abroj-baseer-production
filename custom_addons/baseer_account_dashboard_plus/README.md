# Baseer accounting dashboard extension

This addon extends the Community journal dashboard and uses existing Baseer reports.

| Enterprise-inspired feature | Status |
| --- | --- |
| Posted ledger balance and difference on bank/cash cards | Implemented |
| Delivery-app and custody card classification | Implemented |
| Aged and general-ledger reporting links | Implemented |
| Company-aware ledger, receivable and payable totals | Implemented |
| Agent drafts and current-month tax obligations | Implemented |
| Optional VAT and tobacco report links | Implemented when those addons are installed |
| Per-company details and multi-currency totals | Implemented |
