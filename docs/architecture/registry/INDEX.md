إضافة نقل QA فقط: مرشح APK v51 يضبط أصل HTTPS واحدًا لـQA على الهاتف والمحاكي، ويُبقي أصل المحلي خيار debug صريحًا لا يعمل في release. لا تنقل بيانات BChat المحلية التجريبية إلى QA. نجح بناء release وlint وتحقق التوقيع والحزمة واختبار سياسة عزل outbox بحسب origin؛ هذا قبول بناء لا قبول تشغيل QA. تبقى الترقية **NO-GO** حتى دمج مصدر BChat في `main` عبر PR ناجح، وجرد موديولات الامتداد الاختيارية وعلاج صلاحيات DMS قبل إدخالها، ثم نشر QA بالغلاف المحمي وتجربة الهاتف والمحاكي. لا تُوقف النسخة المحلية قبل قبول QA. التفصيل في [سجل الصلاحيات](../../build-governance/BCHAT-USER-PERMISSIONS-20261014.md#2026-10-14--إعادة-فتح-g0g3-لنقل-bchat-إلى-qa-فقط).
