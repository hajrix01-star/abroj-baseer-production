- رأس غرفة واحد: رجوع، صورة/اسم الغرفة، إجراء المهام ضمن قائمة سياقية عند ضيق العرض؛ لا شعار كبير داخل المحادثة.

- صورة تُعرض بمعاينة واضحة، ملف كسطر قابل للفتح، وصوت كشريط تشغيل داخل الفقاعة. إخفاء التنزيل الدائم من واجهة الصوت إن كان فتح قائمة سياقية آمنة متاحًا؛ لا تغيير عقد التحميل أو التشغيل.
- عارض الطلب في المحادثة بطاقة موجزة لا أزرار ممتدة تغطي رسائل أخرى؛ حقل كتابة واحد مع مرفق وصوت وإرسال، وتحويل ملاحظة الانتظار إلى تنبيه صغير مشروط.
- مكونات عامة مثل الأزرار/الألوان/أحجام اللمس تبقى في `Ui.java`؛ تركيب فقاعة الرسالة والصوت فريد للمحادثة ويظل محليًا. لا حركة متكررة للكتابة أو الإرسال؛ إن أضيف انتقال عابر لاحقًا يُراجع منفصلًا.
