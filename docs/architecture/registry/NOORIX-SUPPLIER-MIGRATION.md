# NSM-SUPPLIER-1 — Noorix supplier and category migration

Classification: ARCHITECTURAL.  Status: QA supplier-master run committed; independent delivery review pending.  Owner: migration lead.  Alternate: independent migration reviewer.  Reference contract: `docs/operations/2026-09-12-noorix-supplier-migration/BUILD-GOVERNANCE.md`.

The change introduces a QA-only private Odoo migration add-on and a local source extractor.  They read the SHA-pinned Noorix PostgreSQL archive through the supplier-master cutoff `2026-09-12 23:59:59 Asia/Riyadh`, make canonical shared suppliers (`res.partner.company_id=False`) and global partner-category tags, and persist write-once source mappings.  Automatic supplier grouping and existing-partner matching use a unique valid Saudi VAT only; names/phones are report-only similarity evidence.  Owner-approved exceptions are exact `NO NAME` rows without a valid VAT (one `مورد نقدي غير مسمى` partner and the `فواتير نقدية صغيرة` tag) and five exact source-label crosswalks: `هيئة الزكاة والدخل`, `وزارة البلدية`, `GOSI`, `اقامات`, and `الشركة السعودية للكهرباء`.  These crosswalks retain individual source mappings and reuse their named existing global Odoo partners; the Saudi Electricity crosswalk preserves both source VAT values and never overwrites the existing target VAT.  They do not permit generalized name matching.  The mapping does not write accounting properties, taxes, journals, balances, documents, production data, or Noorix source data.

The add-on is mounted only by the dedicated QA service.  Run `20260912-noorix-supplier-master-qa-1` committed the approved payload in that database only: 271 new global suppliers, 15 canonical reuse decisions, 449 source-supplier maps, 101 source-category maps and 204 effective target-tag memberships.  The recorded postconditions are 0 mapped-partner scope violations and a repeat invocation is a no-op.  Rollback is disposal and recreation of its separate QA database/filestore.  Independent delivery review, multi-company UI validation and any production decision remain required before the scope expands.
