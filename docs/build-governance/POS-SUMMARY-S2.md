Daily sales/customer averages = complete-day totals / complete operating days. Show recorded totals separately, missing/incomplete/closed counts; unavailable values remain visibly missing in daily lines, no fabricated zero in timeline. Report source actions open summaries/closures. Same backend daily aggregation supports native graph and future dashboard. Current delivery report + native timeline, not a separate custom dashboard.
