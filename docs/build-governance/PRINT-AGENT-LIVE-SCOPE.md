# نشر سجل وتحديث وكيل الطباعة على اللايف

في 2026-11-10 أظهر أودو الإنتاجي أن جسر الطباعة المثبّت هو `19.0.7.8.35` من إصدار `baseer-2026-11-10-pos-new-receipt` عند `e3c53cbfa615a54da418293a01918b0f136328f8`. نشر الوحدة كاملة من #825 يضيف سلوك دفع ومطبخ غير موجود على اللايف.

تأخذ سياسة الإنتاج لقطة الجسر الموجودة في الالتزام «Prepare scoped live snapshot for print agent updater». تتطابق ملفات تشغيل نقاط البيع وملفات إعداد مهام الطباعة والمطبخ مع نسخة اللايف. تتغير فقط سبعة ملفات تخص سجل الوكيل ومسارات تنزيله وتحديثه واختباراته. حافظ الالتزام التالي على شجرة التطوير الأصلية كاملة.

يحتفظ الوكلاء الحاليون بمسارات الاتصال والطباعة نفسها، ولا يثبّت نشر أودو برنامجًا على أجهزة Windows. عرض تحديث Windows محصور في وكيل تجريبي معيّن صراحةً، وتجربة جهاز Windows المستهدف شرط مستقل للتفعيل. يوقف مسار نشر اللايف خدمة أودو وقت النسخ الاحتياطي والترقية ثم يعيدها، ولذلك قد تتوقف الطلبات والطباعة المركزية مؤقتًا.
