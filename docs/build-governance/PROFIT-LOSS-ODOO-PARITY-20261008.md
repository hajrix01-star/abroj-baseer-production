## النطاق المعتمد

يصبح التقرير مطابقاً لبنية أودو التي اعتمدها المالك: الدخل وإجماليه، تكلفة المبيعات،
إجمالي الربح، المصروفات وإجماليها، صافي الربح التشغيلي، الإيرادات الأخرى، المصروفات
الأخرى، صافي الإيرادات الأخرى، وصافي الربح. لا تتغير المعادلة:

`income + income_other - expense_direct_cost - expense - expense_other - expense_depreciation`.

يعرض `expense` و`expense_depreciation` ضمن المصروفات، و`income_other` و`expense_other`
ضمن النتيجة الأخرى. تعرض المصروفات الطبيعية موجبة كما في المرجع؛ الأحمر للسالب الحقيقي
فقط. تنسيق العملة خادمي بفواصل آلاف ومنازل عملة الشركة وأرقام `0–9`.

الشريط يملك فترة حقيقية (شهر/ربع/سنة مالية/مخصص، مع السابق/التالي) ومقارنة حقيقية:
لا مقارنة، 1–3 فترات سابقة، نفس الفترة العام الماضي، أو فترة مخصصة. الحد الثابت أربع
فترات كلية. لا أزرار GAAP أو تحليلي أو تجميع أو بحث أو XLSX شكلية. PDF/A4 جزء من
اكتمال التقرير بعد الشريحة التفاعلية؛ Excel مؤجل صراحةً.

## الحقيقة والحقوق

الفترة والمقارنة يحسبهما الخادم من `fields.Date` و`date_utils` و
`company.compute_fiscalyear_dates`. المصدر AML المرحلة فقط، بتاريخها المحاسبي، شركة
مسموحة ودفاتر مختارة ثابتة لكل الأعمدة، وبنفس ACL وقواعد AML وmove/account/journal
الحالية. لا `sudo` أو حساب JS أو cache مالي مشترك.

تعيد RPC فترات مفاتيحها ثابتة وصفوفاً لها قيم مفهرسة بالمفتاح. الحسابات هي اتحاد
حسابات كل الفترات، بترتيب `(code, id)` ثابت وصفر خادمي عند غياب حركة العمود. تفصيل
الحساب يطلب `period_key` ويتحقق منه؛ وكذلك فتح القيد. يفشل طلب المقارنة كله إن فشلت
أي فترة أو صلاحية.
