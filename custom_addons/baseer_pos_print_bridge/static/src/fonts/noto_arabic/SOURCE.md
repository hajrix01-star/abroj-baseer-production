# Noto Sans Arabic static faces

Official source: https://github.com/notofonts/arabic/releases/tag/NotoSansArabic-v2.012
Archive: NotoSansArabic-v2.012.zip, googlefonts/ttf directory.
Unmodified Medium (500), SemiBold (600), Bold (700) faces; OFL.txt retained verbatim.
Pinned SHA-256 values are in models/print_fonts.py. No network download occurs at runtime.
The kitchen renderer uses these release-local fonts through a child-only fontconfig.
No global font installation, Windows fonts or print-agent modification is required.
