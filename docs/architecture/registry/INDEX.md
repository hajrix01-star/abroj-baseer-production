## مصادر الحقيقة

| المجال | مصدر الحقيقة الساري | لا يستخدم كبديل |
| --- | --- | --- |
| كود النظام | فرع `main` في مستودع GitHub الرسمي | نسخ محلية أو أرشيفات قديمة |
| الإصدار الحي | سياسة إصدار مسمّاة ومحفوظة `root-only` على الخادم | SHA أو أسماء موديولات يرسلها المستخدم إلى Action |
| بيانات أودو | PostgreSQL وfilestore في الإنتاج | GitHub أو أرشيف المصدر |
| تصنيف إنفاق فواتير الموردين | `account.move.line.analytic_distribution` | علامة المورد أو فئة المنتج أو خانة الإدخال الجماعي |
| الاسترجاع | زوج متسق: قاعدة البيانات + filestore | symlink للكود وحده |

## الحدود الثابتة

- النشر يدوي ومقصود من GitHub Actions؛ لا يوجد نشر تلقائي عند `push` أو PR.
- لا تقبل Actions إلا `release_id` مسمى وكلمة تأكيد ثابتة؛ الخادم يقرأ بنفسه
  commit والموديولات من سياسة محمية.
- GitHub يحفظ الكود فقط. لا تدخل الأسرار أو قاعدة البيانات أو filestore أو
  النسخ الاحتياطية إلى Git.
- لوحة فواتير الموردين والمصروفات تقرأ التوزيع التحليلي المخزن في سطور القيد؛
  لا تعيد تخمين التصنيف من بيانات المورد.
