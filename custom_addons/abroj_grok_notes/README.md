# Grok Notes

Personal notes and checklists can be linked to partners, projects, invoices and, when installed, contracting vouchers. Users see their own notes; managers can see notes in their allowed companies. The `grok_upsert` API synchronizes by unique Grok UID using the incoming UTC timestamp for conflict resolution. See `tools/grok_notes_sync/README.md` for the offline-reviewed XML-RPC client.
