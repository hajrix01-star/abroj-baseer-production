# Baseer spreadsheet dashboards

The snapshots are generated by `tools/generate_dashboards.py` and appear in the existing Dashboards app.

The accounting formulas use the current company selected by Odoo's spreadsheet accounting functions. Balance sheet figures include opening balances; income and expense scorecards use month, quarter, or year filters. An arbitrary custom range is summarized as its starting year by these accounting functions. The cash movement ratio is net change in cash divided by current liabilities, not a measure of operating cash flow. Return on assets is used as the investment-return proxy. The purchase report's planned receipt delay measures time from order to planned receipt, not actual receipt time.
