# Report fonts

Downloaded from the Google Fonts repository (2026-10-30):

- IBM Plex Sans Arabic Regular and Bold: https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic
- Amiri Regular and Bold: https://github.com/google/fonts/tree/main/ofl/amiri

Both families use the SIL Open Font License 1.1; the original licenses are
included as plex-OFL.txt and amiri-OFL.txt. Fonts are embedded in report HTML
as base64 TrueType data URLs by res.company.contract_font_css(), including
header and footer HTML, so PDF generation needs no network or system fonts.
