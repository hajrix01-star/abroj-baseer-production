# WS-1 — قرار تسليم إصلاح WebSocket الحي

**التاريخ:** 2026-09-14  
**المرشح المنشور:** Git commit `91e1b8d460541e31cce5881a16081cfbc12ea83a`،
وسم `release-2026-09-14.4`  
**البيئة:** `baseer_prod` على Hostinger، مشروع `baseer-odoo-prod`

## النطاق وخريطة المسار

```text
Internet
  -> Nginx + TLS
     -> 127.0.0.1:18069 -> Odoo HTTP :8069
     -> 127.0.0.1:18072 -> Odoo gevent/WebSocket :8072
Odoo -> baseer-odoo-prod-backend (internal) -> PostgreSQL baseer_prod
```

التغيير اقتصر على نشر منفذ gevent إلى loopback وupstream Nginx مستقل
لـ`/websocket`. لا تعديل على قاعدة البيانات أو filestore أو الإضافات أو
الصلاحيات أو نطاقات TLS.
