## G2 — architecture and exact contracts

```text
Protected Odoo history/media API (unchanged authority)
  → ChatEngine validation + identity/company/member/epoch/TTL guard
    → HistoryArchive (SQLite: scoped rows + proven coverage + latest head)
      → <=180-row moving Timeline window (FlashList, stable IDs)
    → mediaAssociation scoped indexed lookup
      → native media runtime → preview/original private files + SQLite LRU catalog
AsyncStorage identity/outbox/ACKs remain separate and unchanged.
```

Pure core contract (`core/HistoryArchive.ts`):

```ts
type HistoryScope = { account: string; companyId: number; roomId: number; membershipId: number };
type Guard = () => void;
type ArchiveEdge = { kind: 'cached' | 'fetch' | 'gap' | 'end'; cursor: number | null };
type ArchiveSlice = { messages: Message[]; older: ArchiveEdge; newer: ArchiveEdge; latestId: number | null; partial: boolean; unverified: boolean };
interface HistoryArchive {
  commitPage(scope: HistoryScope, page: { beforeId: number | null; history: History }, guard: Guard): Promise<void>;
  read(scope: HistoryScope, query: { direction: 'latest' | 'before' | 'after'; anchorId?: number; limit: number; maxBytes: number }, guard: Guard): Promise<ArchiveSlice>;
  findMedia(scope: HistoryScope, mediaId: number, guard: Guard): Promise<Message | null>;
  importLegacy(scope: HistoryScope, history: History, guard: Guard): Promise<void>;
  reconcile(account: string, allowedScopes: HistoryScope[], mediaAllowed: boolean, guard: Guard): Promise<void>;
  purgeAccount(account: string, guard: Guard): Promise<void>;
}
```

Account is origin/database/UID private prefix, NOT session epoch and contains no credential. All scope columns participate in composite primary/index keys. Message row stores bounded validated JSON, byte size and media ID. Scope state stores latest snapshot head, cache usage/touch. Coverage intervals stored atomically with page rows: nonterminal page proves `[oldestReturned, requestBefore)` or latest `[oldestReturned,maxReturned+1)`; terminal older page extends to0. Merge overlapping/touching intervals only. IDs need not be consecutive. Reads stop at disconnected interval; offline gap is not beginning/end. Latest head is authoritative snapshot metadata, not MAX(old cached row). Empty terminal latest clears stale scope; before-empty terminal clears only `<before`. Reconcile missing rows inside authoritative page interval. Migration imports legacy rows but treats both continuity edges as unknown, never trusts old buggy cursor as proof of completeness.

DB adapter serializes reads/writes and transactions. Guard at entry, after awaits and immediately before COMMIT; throw rolls back all SQL mutation. Engine also orders archive writes/purge in its storage serial lifecycle and checks captured epoch after network/DB completion, so stale sessions cannot reinsert after purge. Reconcile deletes unauthorized/company/member scopes (and media JSON when media permission disappears). Invalid/expired remembered identity cannot expose archive. Logout/account switch purges applicable account rows, including WAL checkpoint after deletion; no token in DB. Exact native-file privacy behavior remains authoritative.

Migration: import each bounded existing history only under verified scope in transaction, then remove only its exact AsyncStorage `/history` key after successful guarded ACK. Failed/interrupted import retains source and retry is idempotent. Never delete/rewrite outbox, identity, ACKs or pending attachment records as migration. Legacy large/broken history handling remains limited to history cache. Rollback is previous APK using its old cache while durable sends remain; new cache schema is disposable, not a server migration.

Core/UI: bounded moving window latest/browsing; explicit older action performs at most one missing network page then merges <=180/512KiB, trimming opposite side to cached edge. Poll/flush archives new head but does not replace browsing window or emit old-message sounds. Explicit latest returns to current head. Optional newer reads adjacent connected cached page; no invented server after_id. Preserve drafts/replies, stable anchors, pending state, follow/IME rules. Per-room page deduplication and generation fencing. `mediaAssociation(room: Room | number, mediaId: number): Promise<Message | null>` validates hot canonical row then archive index under same rights and TTL; runtime descriptors never authorize files.

Media: automatic preview requests authenticated `/bchat/api/v2/media/:id/thumbnail` only when trusted `thumbnail_available=true`; no failed-thumbnail fallback to original. Existing cached original can display for legacy no-thumbnail records; otherwise placeholder until deliberate tap. Thumbnail response JPEG<=128KiB/256×256, validate MIME/length/JPEG structure/dimensions, compute own SHA for future corruption checks (server does NOT provide thumb SHA). Original exact original-size/SHA validation unchanged. Separate `media-ID-preview.jpg` and original paths. `localMediaLease(room,descriptor,variant)` acquires pin inside serialized media work before return; release for recycled/hidden image, closed viewer, stopped audio, or external FileViewer onDismiss/error; permission revoke still removes inaccessible content. Catalog separate export from same SQLite connection: `list(actor)`, `put(actor,entry)`, `remove(actor,uri)`, `touch(actor,uri,at)`; entry `{uri,bytes,sha256,usedAt}` cache-only, validated paths, no message body/names. Account-scoped prefix and room/member grammar revalidated, max5000 entries. Stage counts reconciled once and updated on create/remove.
