# Baseer ERP — سجل البناء

## عقد البناء — مسودة
- الهدف: تخصيص Odoo 19 Community ليكون Baseer ERP، مع هوية مرئية وموديولات جاهزة وتوسعات مخصصة.
- المستخدمون والرحلات والموديولات الأولى: لم تحدد بعد.
- النطاق المصرح به الآن: تنزيل المصدر الرسمي وتشغيل بيئة تطوير محلية معزولة باستخدام Docker، من دون تخصيصات وظيفية أو بيانات حقيقية.
- قبول هذه الخطوة: وجود مستودع مصدر سليم في `odoo/`، على فرع `19.0`، وبيئة Odoo/PostgreSQL محلية قابلة للإقلاع، مع مسارات منفصلة لإضافات Baseer والإضافات الخارجية.
- لا تشمل هذه الخطوة تعديل كود Odoo أو إنشاء مستودع GitHub أو تشغيل بيانات إنتاج أو اعتماد سياسات مالية أو ضريبية.
- التخصيص المقترح لاحقاً: إضافات Baseer منفصلة عن المصدر الرسمي، بعد بوابات البناء.
