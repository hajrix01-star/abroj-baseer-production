## حدود الدليل

- التوزيع النسبي افتراض معاينة معلن، وليس موافقة سياسة إنتاج.
- شركة واحدة وSAR، وحد قراءة 10000 ومدى لا يتجاوز 366 يوماً؛ لا قياس سعة إنتاج.
- البنود ذات الضريبة غير المثبتة تبقى بكامل قيمتها مع تشخيص؛ لا افتراض لقسمة جميع المدفوعات على 1.15.
- تمت مراجعة أدلة سيناريوهات ORM التي نفذها الفريق؛ لم يعد المراجع تشغيلها، وأجرى مباشرة فحص الخوارزمية وملفات التصدير فقط.
- عبارة «كل تغييرات قاعدة البيانات رجعت» في دليل edge أوسع من المثبت: رجعت بيانات السيناريوهات والقيود، لكن السجل يثبت حفظ تدقيق أخطاء متعمدة عبر اتصال مستقل (`Persisted durable failure audit`). لا أثر مالي لهذه السجلات، وهي داخل QA.
- الفصل الحالي فصل قاعدة وعملية ومنفذ، مع مشاركة خدمة PostgreSQL وحجم Odoo؛ ليس sandbox مستقلاً بالكامل.
- فحص عدم تغيير main النهائي وقياسات وصور رحلات الواجهة يجمعها قائد التنفيذ، وليسا ادعاء تنفيذ مستقل في هذه الوثيقة.
